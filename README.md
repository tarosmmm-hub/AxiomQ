# QuantLab (nombre provisional)

Plataforma de infraestructura cuantitativa para crear, ejecutar, comparar y analizar estrategias
de trading algorítmico — backtesting, paper trading y experiment tracking — sin dinero real.

> **Estado: Fase 0 (arquitectura).** Todavía no hay código ejecutable. Los comandos `make install`,
> `make dev`, `make test`, etc. llegan en la Fase 1.

Los resultados de la plataforma son simulaciones sobre datos históricos y no garantizan
rentabilidad futura. QuantLab no ejecuta operaciones con dinero real.
